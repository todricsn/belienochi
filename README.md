# Белые Ночи — локальный сайт

Одностраничный сайт гостиницы и хостела на HTML, CSS и JavaScript.

## Запуск

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

После запуска сайт доступен по адресу `http://127.0.0.1:4173/`.

## Структура

- `index.html` — контент и разметка;
- `styles.css` — визуальная система, адаптив и анимации;
- `rooms.html` и `rooms.css` — шаблон каталога номеров с восемью карточками-заглушками;
- `script.js` — меню, появление блоков, параллакс и прогресс прокрутки;
- `assets/images/` — финальные изображения и логотип;
- `source-old/` — распакованная копия старого сайта для сверки.

## Изображения

Файлы `gallery-room-*.png` в `assets/images/restored/` взяты напрямую из старого сайта. Они увеличены в 4 раза алгоритмически (Lanczos), с мягким шумоподавлением и резкостью — без генеративной перерисовки. Два файла `hero-room-*-enhanced.png` дополнительно восстановлены встроенным ImageGen в режиме строгого сохранения мебели, текстиля, планировки, ракурса и исходной цветовой гаммы; они используются в коллаже первого экрана.

ImageGen также использовался для бережного улучшения двух оригинальных фотографий в коллаже. Отдельные полностью перегенерированные интерьерные концепты сохранены в проекте как черновики, но сайт их больше не использует.

1. Фасад — отдельные концепты здания для нижних блоков; 16:9.
2. Логотип — обновлённый старый знак с верблюдом в круге и прямая прописная надпись «БЕЛЫЕ НОЧИ» без дополнительного дескриптора, на прозрачном фоне.

Цены взяты со страницы организации в 2ГИС и сопровождаются пометкой о том, что они не являются публичной офертой.
